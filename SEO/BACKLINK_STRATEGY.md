## Channels

- **Open source**: repo READMEs link canonical case-study URLs; docs, examples, architecture diagrams, releases. Never manipulate stars/forks.
- **Canonical syndication**: dev.to (`canonical_url`), Hashnode (`republished from`), Medium import — publish on mahirmalik.in first, syndicate after GSC shows indexed (see `docs/traffic-playbook.md`).
- **Awesome-list PRs**: propose Confluence/Sellable under fitting sections with one-line proof (templates in `docs/traffic-playbook.md` C4).
- **Staggered directories**: Product Hunt, BetaList, AI tool directories per docs C3 — never mass-submit in one day.
- **Resource pages / educators**: pitch gamma visuals + debugging tree once published with figures.
- **Interviews / podcasts / newsletters**: accept genuine invitations; talking points = first-hand builds.
